# TjuaeUI

TjuaeUI — настольный клиент и WebUI платформы агентов Tjuae. Он объединяет диалоги, инструменты, файлы, расширения и запланированные задачи.

Выполните `bun install --frozen-lockfile`, затем `bun run start`. Миграция не поддерживает прежние названия, настройки, переменные окружения, протоколы или каталоги.

Подробности приведены в [основной документации](../../readme.md).
