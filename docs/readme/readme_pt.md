# TjuaeUI

O TjuaeUI é o cliente desktop e a WebUI da plataforma de agentes Tjuae. Ele reúne conversas, ferramentas, arquivos, extensões e tarefas agendadas.

Execute `bun install --frozen-lockfile` e depois `bun run start`. Esta migração não oferece compatibilidade com nomes, configurações, variáveis, protocolos ou diretórios do produto anterior.

Consulte a [documentação principal](../../readme.md).
