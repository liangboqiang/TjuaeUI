# TjuaeUI

TjuaeUI — настільний клієнт і WebUI платформи агентів Tjuae. Він об’єднує діалоги, інструменти, файли, розширення та заплановані завдання.

Виконайте `bun install --frozen-lockfile`, а потім `bun run start`. Міграція не підтримує попередні назви, налаштування, змінні середовища, протоколи чи каталоги.

Докладніше дивіться в [основній документації](../../readme.md).
