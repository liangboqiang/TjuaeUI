# TjuaeUI

TjuaeUI es el cliente de escritorio y la WebUI de la plataforma de agentes Tjuae. Integra conversaciones, herramientas, archivos, extensiones y tareas programadas.

Ejecuta `bun install --frozen-lockfile` y después `bun run start`. Esta migración no incluye compatibilidad con nombres, configuraciones, variables, protocolos ni directorios del producto anterior.

Consulta la [documentación principal](../../readme.md).
