# TjuaeUI

TjuaeUI, Tjuae ajan platformunun masaüstü istemcisi ve WebUI uygulamasıdır. Sohbetleri, araçları, dosyaları, uzantıları ve zamanlanmış görevleri tek arayüzde toplar.

Önce `bun install --frozen-lockfile`, ardından `bun run start` komutunu çalıştırın. Bu geçiş eski ürün adları, ayarlar, ortam değişkenleri, protokoller veya dizinler için uyumluluk sağlamaz.

Ayrıntılar için [ana belgeye](../../readme.md) bakın.
